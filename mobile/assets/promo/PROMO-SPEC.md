# โฆษณาหน้าแรก — สเปกรูป / วิดีโอ

อ้างอิง `HomePromoCarousel` — **2 แถบเท่ากัน** แบบตัวอย่าง

| แถบ | เนื้อหา | อัตราส่วน |
|------|--------|-----------|
| **ซ้าย** | สไลด์รูป (PageView + จุด) | **3:4** |
| **ขวา** | วิดีโอสั้น + การ์ดข้อมูลด้านล่าง | **3:4** |

## ขนาดรูปที่แนะนำ (สไลด์ / โปสเตอร์)

| รายการ | ค่า |
|--------|-----|
| อัตราส่วน | **3:4** |
| พิกเซลแนะนำ | **750 × 1000** |
| ไฟล์ | PNG, WebP, JPEG, GIF ≤ 512 KB |

## วิดีโอสั้น (ขวา)

- ใส่ `videoUrl` ในรายการโฆษณา (ตอนนี้รองรับใน config `home_short_video`)
- ค่าเริ่มต้น: คลิปทัวร์ห้องจาก `DemoMedia.sampleTourVideoUrl` (Pexels)
- เล่นแบบเงียบ + ลูปอัตโนมัติ
- ถ้าโหลดวิดีโอไม่ได้ จะใช้รูปโปสเตอร์แทน

## รูปตัวอย่าง

- ใช้ `DemoMedia` (Unsplash ห้องคอนโด/บ้าน) แทน picsum แบบสุ่ม
