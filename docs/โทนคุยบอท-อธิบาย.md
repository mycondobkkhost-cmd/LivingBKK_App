# โทนคุยบอท — อธิบายสำหรับเจ้าของโปรเจกต

## ไฟล์ `supabase/seed/owner_inquiry_voice_th.json` คืออะไร?

**ไม่ต้องเปิดไฟล์นี้เพื่อใช้แอป** — ลูกค้าและเจ้าของไม่เห็นไฟล์นี้เลย

เป็นแค่ **บันทึกตัวอย่างประโยค** สำหรับทีมพัฒนา ใช้ปรับให้บอทคุยโทนเดียวกับคุณ (เหมือนคุณสอนพนักงานใหม่)

| ส่วนในไฟล์ | ความหมาย |
|------------|----------|
| `owner_inquiry_offer` | ประโยคตอนลูกค้าถามเรื่องที่ต้องไปถามเจ้าของ |
| `examples` | ตัวอย่างบทสนทนา — **ให้คุณเติมทีหลัง** |

### วิธีใช้จริง (เมื่อมีตัวอย่างจากคุณ)

1. คุณส่งบทสนทนาตัวอย่างในแชท Cursor (ไม่ต้องแก้ JSON เอง)
2. ทีมพัฒนาคัดลงไฟล์นี้ หรือปรับในโค้ดบอท
3. Deploy ฟังก์ชัน `chat-turn` อีกครั้ง

---

## ระบบสอบถามเจ้าของทำงานยังไง (ภาษาคน)

```
ลูกค้าถามเรื่องราคา/ห้องว่าง/เงื่อนไข
        ↓
บอทชวนรวมคำถามก่อน (ยังไม่ส่งเจ้าของทันที)
        ↓
ลูกค้าพิมพ์เพิ่มได้เรื่อยๆ → บอทสรุปให้ดู
        ↓
ลูกค้ากด「พร้อมส่งคำถามให้เจ้าของ」หรือพิมพ์「ส่งเลย」
        ↓
ระบบส่งให้เจ้าของ (แจ้งเตือนในแอป)
        ↓
เจ้าของตอบ → บอทแปลงประโยค → ส่งกลับลูกค้าในแชท
```

### เลขห้อง / ชั้น / ทิศ

- **ไม่ถามเจ้าของในแชททั่วไป**
- บอทบอกว่ารายละเอียดนี้จะแจ้งเมื่อ**นัดดูห้อง**
- กด「ขอนัดดู」ในห้องแชทประกาศ

## ถ้าอยากให้บอทคุยเหมือนคุณ

ส่งตัวอย่างแบบนี้ในแชท:

> ลูกค้าถาม: สัญญา 2 ปี ลดได้ไหม  
> อยากให้บอทตอบ: …  
> เจ้าของตอบกลับมา: …  
> อยากให้บอทบอกลูกค้า: …

ไม่จำเป็นต้องแก้ JSON เอง
